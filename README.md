# Sports Tracking and Pose Lab

Two reproducible research pilots by **Nicholas Reign Lugu** exploring movement data, statistical modeling, machine learning, and measurement reliability.

## Studies

| Study | Question | Methods | Read |
|---|---|---|---|
| Soccer movement forecasting | Do nearby players and the ball improve short-term forecasts? | Ridge regression, boosted trees, match-held-out evaluation, calibration, missing-observation experiment | [Project](soccer/) · [Research memo](soccer/RESEARCH_MEMO.md) |
| Basketball shooting mechanics | How consistent are shooting movements within and between athletes? | Motion alignment, multilevel variance components, trajectory PCA, grouped and chronological outcome evaluation | [Project](basketball/) · [Research memo](basketball/RESEARCH_MEMO.md) |

[Open the interactive research hub](https://lugureign.github.io/sports-tracking-pose-lab/). Each study also has a self-contained HTML explorer in its `docs/` folder that works offline.

## Scope

The soccer study uses three Metrica sample matches, with one final evaluation match. The basketball study uses MLSE SPL free-throw motion data from five non-professional participants. These are research pilots, not validated scouting or coaching products. Positional tracking and joint-level pose data are distinguished throughout.

Each study includes actual source inputs or compact source-derived input arrays, provenance, reproducible Python code, numerical results, tests, an interactive explorer, and a research memo. Basketball input arrays preserve the selected source markers at full precision; their transformation and omitted markers are documented.

## Reproduce

First run `python restore_large_files.py` from the repository root. Large soccer inputs and prediction outputs are stored in lossless chunks, each verified against the original SHA256 on reconstruction. Then run each study from its own directory. See its README for dependencies and complete commands. Soccer can extract bundled inputs offline. Basketball reads its bundled NPZ inputs offline; `prepare_data.py` can reconstruct those arrays from the pinned upstream repository.
